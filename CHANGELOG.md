# Changelog

## 1.0.0 (16 November 2026)

- The first release, with five skills: `cms-orbit` to choose the route for a task, `cms-orbit-model-content`, `cms-orbit-build-frontend`, `cms-orbit-use-mcp` and `cms-orbit-use-cli`.
- Registers the CMS Orbit MCP server, `https://app.bifrostorbit.com/cms/mcp`, with sign-in in the browser.
- Manifests for Claude Code, Codex and Cursor, and skills that any agent can install with `npx skills add bifrost-orbit/agent-plugin`.
